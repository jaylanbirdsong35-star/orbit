# Orbit — visual identity website

Upload `index.html`, `style.css`, `script.js`, and the entire `assets/` folder to the root of your GitHub Pages repository. Keep the existing README if you prefer.

The original page structure, tabs, and layout are retained. Uploaded images are separate local files and use CSS `background-size: contain` so the entire image remains visible without cropping or distortion. The background of a container may show around an image when its aspect ratio differs from the container.

The strategy text comes from the supplied PDF. The About copy was transcribed from the PDF reference screenshot. The five color swatches are approximate visual matches, not exact approved color codes. No standalone About photograph was supplied. Empty application slots remain available.

Important: editing in a browser does not publish to GitHub. For future changes, edit source files or send updated content to be embedded.
